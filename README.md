# Palworld Telegram Bot
<a href="https://ibb.co/R4s6g8zx"><img src="https://i.ibb.co/QjTHJ0r2/photo-2026-08-02-14-03-10.jpg" alt="photo-2026-08-02-14-03-10" border="0"></a>

Telegram бот с Mini App для управления сервером Palworld и отображения статистики.

## Возможности

- 📊 Отображение статистики сервера (FPS, uptime, игроки онлайн)
- 👥 Список игроков онлайн с информацией
- 📢 Отправка объявлений на сервер
- 🚫 Управление игроками (kick, ban, unban)
- 💾 Сохранение мира
- 🔄 Управление сервером (shutdown, force stop)
- 📱 Mini App для удобного управления через веб-интерфейс

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка Palworld сервера

В файле конфигурации сервера (`DefaultPalWorldSettings.ini` или `PalWorldSettings.ini`) добавьте в секцию `[ServerSettings]`:

```ini
[ServerSettings]
RESTAPIEnabled=True
RESTAPIPort=8212
AdminPassword=ваш_пароль
```

**ВАЖНО**: После изменения конфигурации обязательно перезапустите сервер Palworld!

### 3. Создание файла .env

**На Windows (PowerShell):**
```powershell
Copy-Item env.example.txt .env
```

**На Windows (CMD):**
```cmd
copy env.example.txt .env
```

**На Linux/Mac:**
```bash
cp env.example.txt .env
```

Затем откройте `.env` и заполните значения:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
PALWORLD_SERVER_URL=http://localhost:8212
PALWORLD_ADMIN_PASSWORD=ваш_пароль
WEB_SERVER_HOST=0.0.0.0
WEB_SERVER_PORT=8000
WEB_SERVER_URL=http://localhost:8000
```

### 4. Запуск проекта

Поддерживаются три варианта запуска:

1. **Веб + Бот + No-IP (основной вариант для Mini App)**  
   ```bash
   python run_with_noip.py
   ```
   Скрипт:
   - запускает веб‑сервер (с SSL, если доступны сертификаты),
   - формирует URL из `NOIP_HOSTNAME`,
   - обновляет настройки в `.env`,
   - обновляет Mini App URL в Telegram‑боте,
   - запускает Telegram‑бота.

2. **Веб + Бот (без No-IP, используется WEB_SERVER_URL из .env)**  
   ```bash
   python run_all.py
   ```
   Скрипт:
   - запускает веб‑сервер (учитывая `SSL_CERT_PATH` / `SSL_KEY_PATH`, если заданы),
   - запускает Telegram‑бота,
   - ничего не меняет в `.env` и не трогает No-IP.

3. **Только Веб (без бота)**  
   ```bash
   python run_web.py
   ```
   Скрипт:
   - запускает только веб‑сервер (учитывая `SSL_CERT_PATH` / `SSL_KEY_PATH`, если заданы).

**Важно - Настройка портов и SSL:**

No-IP работает на стандартных портах (80 для HTTP, 443 для HTTPS), а ваш веб-сервер работает на порту 8000.

**1. Настройка проброса портов в роутере:**

1. Войдите в настройки роутера (обычно `192.168.1.1` или `192.168.0.1`)
2. Найдите раздел "Проброс портов" (Port Forwarding) или "Виртуальные серверы"
3. Добавьте правила:
   - **Внешний порт 80** → **Внутренний порт 8000** → **IP вашего компьютера** (например, `192.168.1.100`)
   - **Внешний порт 443** → **Внутренний порт 8000** → **IP вашего компьютера**
4. Сохраните настройки

**2. Настройка SSL сертификата Let's Encrypt (обязательно для Telegram Mini App):**

Telegram Mini App требует HTTPS. В проекте есть встроенная поддержка Let's Encrypt.

**Автоматическая настройка SSL:**

```bash
python setup_ssl.py
```

Этот скрипт:
- Получит бесплатный SSL сертификат от Let's Encrypt
- Сохранит сертификаты в нужное место
- Автоматически настроит HTTPS на веб-сервере

**Требования:**
- Порт 80 должен быть открыт и доступен из интернета
- Домен должен указывать на ваш IP адрес
- Веб-сервер должен быть остановлен на время получения сертификата

**Установка Certbot (если нужно):**

**На Windows через WSL:**
```bash
wsl --install
# В WSL:
sudo apt update && sudo apt install certbot
```

**Обновление сертификата:**

Сертификаты Let's Encrypt действительны 90 дней. Для обновления:
```bash
python renew_ssl.py
```

Рекомендуется настроить автоматическое обновление через cron (Linux) или Task Scheduler (Windows).

**Примечание**: Убедитесь, что порт 8000 открыт в файрволле Windows.

### 6. Запуск

**Запуск с No-IP (основной вариант):**
```bash
python run_with_noip.py
```
Этот скрипт:
- Запускает веб-сервер с SSL (если доступен)
- Формирует URL из No-IP hostname
- Обновляет настройки в .env
- Обновляет кнопку Mini App в Telegram боте
- Запускает Telegram бота

### 7. Использование

1. Откройте вашего бота в Telegram
2. Отправьте команду `/start`
3. Используйте кнопки для управления или откройте Mini App

## Команды бота

- `/start` - Главное меню
- `/announce <текст>` - Отправить объявление на сервер

## Возможности Mini App

- **Дашборд**: Статистика сервера (название, версия, FPS, uptime, количество игроков)
- **Игроки**: Список игроков онлайн с возможностью kick/ban (для администраторов)
- **Чтение сохранений**: Просмотр данных игроков из файлов .sav (только чтение)
- **Управление**: Отправка объявлений, сохранение мира, остановка сервера

## Решение проблем

### Ошибка подключения к серверу

- Проверьте, что сервер Palworld запущен
- Убедитесь, что `RESTAPIEnabled=True` в конфигурации
- Проверьте правильность URL и порта в `.env`
- Убедитесь, что сервер перезапущен после изменения конфигурации

### Ошибка 404: route_handler_not_found

Если вы получаете ошибку `API Error 404: {"errorCode": "errors.com.epicgames.httpserver.route_handler_not_found"}`:

1. **Проверьте настройки сервера:**
   - Убедитесь, что `RESTAPIEnabled=True` в конфигурации
   - Проверьте правильность `RESTAPIPort` (по умолчанию 8212)
   - Убедитесь, что сервер перезапущен после изменения настроек

2. **Проверьте URL в .env:**
   - URL должен быть в формате `http://localhost:8212` (или ваш IP)
   - Не добавляйте `/v1` или другие пути к URL
   - Убедитесь, что порт совпадает с `RESTAPIPort`

3. **Проверьте версию Palworld:**
   - REST API доступен начиная с версии 0.2.0.0
   - Убедитесь, что вы используете актуальную версию сервера

### Mini App не открывается

- Убедитесь, что веб-сервер запущен
- Проверьте правильность URL в настройках бота
- Для доступа из интернета используйте No-IP динамический DNS
- Если используете белый IP, убедитесь, что порт открыт в роутере и файрволле

### Ошибки авторизации

- Проверьте правильность пароля администратора
- Убедитесь, что `AdminPassword` в конфигурации сервера совпадает с `PALWORLD_ADMIN_PASSWORD` в `.env`

### Другие частые ошибки

**Ошибка: "Connection refused"**
- Сервер не запущен
- Неправильный URL или порт
- Файрволл блокирует подключение

**Ошибка: 401 Unauthorized**
- Неправильный пароль администратора
- Пароль в `.env` не совпадает с `AdminPassword` в конфигурации

## Безопасность

⚠️ **ВАЖНО**: 

- REST API Palworld не предназначен для прямого доступа из интернета
- Используйте его только в локальной сети или через защищённый прокси
- Не публикуйте файл `.env` в публичных репозиториях
- Используйте сильный пароль администратора

### Использование белого IP

Если у вас белый (публичный) IP адрес:

1. **Настройте проброс портов на роутере:**
   - Откройте настройки роутера
   - Найдите "Port Forwarding" или "Виртуальные серверы"
   - Пробросьте порт 8000 (или другой, указанный в `.env`) на ваш компьютер

2. **Настройте файрволл:**
   - Разрешите входящие соединения на порт 8000 в Windows Firewall

3. **Используйте HTTPS (рекомендуется):**
   - Для продакшена используйте Cloudflare Tunnel (бесплатно, с HTTPS)
   - Или настройте nginx с Let's Encrypt для HTTPS
